Privacy Policy

Effective Date: October 2026. Draft, needs legal review before launch.

1. Overview

WanderWise AI provides automated travel planning. This Privacy Policy describes how information is collected, used, and stored when accessing this service.

2. Information We Collect

We collect only the information necessary to provide the travel planning service:

  • Google Account Information: User name, email address, profile photo URL, and Google identifier returned during OAuth authentication.
  • Trip Inquiries: Text prompts and travel queries submitted in the planner.
  • Session Data: HTTP session cookies used to authenticate requests.

3. Third-Party Service Providers

Trip prompts are processed by third-party APIs to gather travel data:

  • Groq: LLM inference for travel synthesis.
  • Tavily Search: Web search for hotel suggestions.
  • AviationStack: Flight status lookup.
  • OpenWeatherMap: Weather forecasts.
  • OpenTripMap: Local attraction data.

4. Data Storage and Retention

Travel plans and conversation checkpoints are stored in a PostgreSQL database. Trips you save with the Save button are kept only in your browser's local storage. We do not sell user data, run advertisements, or track user activity across other websites.
